# Tally

Tally is a recovery-oriented flight recorder for demurrage and detention
disputes. It records source observations and makes their history replayable
into an isolated CockroachDB target.

This public branch contains only fictional demonstration identities, synthetic
fixtures, and sanitized recovery evidence. Production captures, source URLs,
cloud identifiers, database connection metadata, object versions, and
production hashes are intentionally excluded.

Every file under `tests/fixtures/`, including
`tests/fixtures/defective_missing_field7.pdf`, is fictional synthetic
demonstration data created solely for automated tests. Names, identifiers,
dates, amounts, and source text in those fixtures are not production evidence
or external outcomes.

See `artifacts/recovery/gate-0/` for the public Gate 0 report and replay
methodology.
